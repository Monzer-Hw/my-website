Sudoku solver

In progress

Try it Code

Photograph a puzzle and get it solved. An OpenCV pipeline finds the grid and reads the digits, you confirm or correct what it recognized, and a constraint solver finishes the job.

  • SolverConstraint propagation with MRV ordering and naked and hidden singles; GAC (Régin) held back until it's needed.
  • APIFastAPI with a discriminated-union response, so the frontend handles every outcome explicitly.
  • UXRecognise, confirm, edit, solve. The user stays in control when recognition is unsure.

Python 3.13, FastAPI, OpenCV, Pytest, Docker, React, TypeScript, Vite, Tailwind

Invoice intake automation

Built 2024

Try it Code

An n8n workflow that picks up supplier invoices from a shared inbox, extracts the fields with an LLM, checks them against purchase orders and posts clean records to the ERP. Anything uncertain lands in a review queue instead of being guessed.

  • ExtractionStructured output validated against a schema, with one retry before a human sees it.
  • SafetyConfidence threshold per field, so a wrong amount never posts silently.
  • ResultAround 25 hours of manual entry removed per week.

n8n, Python, Pydantic, PostgreSQL

About.

I build AI systems that companies can actually run: retrieval over messy documents, LLM services with clear contracts, and automations that save people real hours.

I started in data science, training text classifiers for customer support teams. Once large language models arrived, the hard part moved from the model to everything around it: getting clean data in, retrieving the right context, and knowing whether an answer is good. That's the work I enjoy most.

Today I work as an AI engineer on document intelligence and internal assistants. I write the spec before the code, keep services typed and tested, and design provider-agnostic interfaces so a new model is a config change, not a rewrite.
